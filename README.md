## 🔍 How I Study

문제를 처음부터 정답 풀이를 보고 따라가기보다 **먼저 직접 구현하는 것**을 우선합니다.

```text
문제 이해
   ↓
직접 풀이
   ↓
제출 / 테스트
   ↓
실패한 케이스 확인
   ↓
반례 분석
   ↓
리팩터링
   ↓
다른 풀이와 비교
```

정답 여부뿐 아니라 다음 내용까지 함께 확인합니다.

- 놓친 조건과 경계값 확인
- 실패한 테스트케이스 원인 분석
- 불필요한 반복 제거
- 더 적절한 자료구조가 있는지 검토
- 시간복잡도 확인
- Pythonic한 풀이와 비교
