# Python Coding Test Solutions

프로그래머스 등 코딩 테스트 플랫폼에서 해결한 Python 문제 풀이를 [BaekjoonHub](https://github.com/BaekjoonHub/BaekjoonHub)로 자동 기록하는 학습 저장소입니다.

- 현재 업로드 플랫폼: 프로그래머스
- 사용 언어: Python
- 업로드 방식: 정답 제출 후 BaekjoonHub 자동 커밋
- 목적: 알고리즘 문제 풀이 기록과 복습

## 저장 구조

```text
Python/
└── 프로그래머스/
    └── {level}/
        └── {problem}/
```

문제별 디렉터리에는 BaekjoonHub가 생성한 문제 정보와 제출 코드가 저장됩니다. 이 저장소의 커밋과 파일 구조는 확장 프로그램 설정 및 지원 플랫폼에 따라 자동으로 변경될 수 있습니다.

## 참고

- 각 풀이 코드는 개인 학습 기록입니다.
- 문제 설명과 예시는 각 코딩 테스트 플랫폼의 이용 조건과 권리에 따릅니다.
- 자동 업로드가 중단되면 BaekjoonHub의 GitHub 연결 상태를 먼저 확인합니다.
